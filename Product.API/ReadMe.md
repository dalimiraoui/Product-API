## About This Project
- This is my **first time working with Visual Studio**.
- The project is an **ASP.NET Core 8 Web API**, built to understand the fundamentals of API development.
- It follows best practices and includes authentication, database integration, and more.

## Learning Goals
- Get familiar with **Visual Studio 2022**.
- Understand **ASP.NET Core Web API** development.
- Explore **Entity Framework Core** for database interactions.
- Implement **JWT authentication** and API security.
- Work with **Swagger (OpenAPI) for API documentation**.

## Technologies Used
- **.NET Core 8**
- **C#**
- **Entity Framework Core**
- **JWT Authentication**
- **Swagger**
- **SQL Server**
